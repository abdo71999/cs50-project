# Mission

## Why this project exists

Build Physics Data Lab as a practical bridge from CS50 coursework to real software engineering.

## What the learner is developing

- Build and understand a small Flask application that accepts CSV data and performs regression analysis.
- Learn to make decisions about HTTP, sessions, file storage, validation, data processing, testing, security, and system design.
- Become comfortable using established libraries in application code while understanding the concepts they abstract.
- Develop habits appropriate for a junior software engineer working on a real team.

## Learning outcome

The user remains the primary author. The assistant teaches through purposeful exercises, progressive hints, review, and verification so the user can explain and extend the system independently.
