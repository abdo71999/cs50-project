Before you begin

Your file can contain other information, but the two columns selected for regression must meet these requirements.

  • Use a readable .csv file with a first row of column names.
  • Choose two different columns for X and Y.
  • The selected X and Y columns must contain numbers, with no blank or missing values.
  • Provide at least three observations.
  • Both selected columns must vary; a column containing the same value in every row cannot be fitted.
